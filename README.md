# Habit Matrix

A modular, minimalist habit tracking dashboard built with **React**, **Vite**, **Tailwind CSS**, and **Lucide Icons**, retaining the sleek dark aesthetic (`#09090b` background with `#f5d087` gold accents).

## Features

- **HeaderStats**: Active habits count, average daily completed count, and animated circular SVG progress ring.
- **HabitMatrix**: Interactive month view (Days 1–31) with completed (`✓`), missed, due today, and upcoming day indicators. Add new habits and delete existing ones.
- **ConsistencyTrend**: Smooth SVG bezier line chart depicting day-by-day habit completion rates with interactive hover tooltips.
- **HabitAnalysis & TopHabits**: Progress bars per habit and top-ranking habits breakdown.
- **LocalStorage Persistence**: All habit states, additions, and deletions persist across page reloads.

## Development

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
